## 1. 要回答的两个问题
- **Q1 方差从哪来**：同一输入重复运行时，agent 的结果和行为差异分别有多少来自题目、模型精度、服务配置（prefix cache）、采样温度、随机种子，以及服务栈的数值非确定性。
- **Q2 需要多少**：要让一次评测"可靠"（例如两个系统的比较方向稳定，或均值的标准误小于某阈值），每题要重复几次、需要多少道题。

## 2. 结局变量
| 层级 | 变量 | 类型 | 说明 |
|---|---|---|---|
| 每次运行 | EM | 0/1 | 主结局（与 HotpotQA 惯例一致） |
| 每次运行 | F1 | [0,1] 连续 | 次结局，对部分正确更敏感 |
| 每次运行 | 动作序列签名 | 类别 | 每步 (动作, 参数) 拼接后取哈希；用于"不同动作序列数"（与 2602.11619 可比） |
| 每次运行 | 步数、搜索次数、格式错误数 | 计数 | 行为层面 |
| 题目 × 条件 | 众数答案占比、不同答案数、不同动作序列数、首次分歧步 | 汇总 | 一致性指标（描述性，不进模型） |

## 3. 设计结构（关键）
实验单元的嵌套关系：

```
题目 q  ×  条件 c（温度 × 缓存 × 精度 …）
            └─ 种子 s（每个 q×c 下 S 个不同种子）
                  └─ 同种子重复 r（每个种子 R 次，R≥2 才能估计服务栈非确定性）
```

- **为什么要"同种子重复"**：2609.04748 证明贪心 + 关缓存时重复运行位级相同，开缓存后才出现分歧。温度 > 0 时，如果每次重复都换种子（不启用同种子重复时），"采样方差"和"服务栈数值非确定性"会混在一起分不开。让同一种子重复 R 次：同种子之间的差异 = 服务栈非确定性；不同种子之间的差异 = 采样方差。
- 实现：runner 已支持 `replicates_per_seed`（默认 1 = 每次重复换种子）。例如 `n_repeats: 20, replicates_per_seed: 2` = 10 个种子 × 每种子 2 次。
- **温度 0 的格子**：种子不起作用，所有重复都在测服务栈非确定性。

## 4. 模型（Q1：方差成分分解）
### 4.1 主模型：线性混合效应模型（以 F1 和 EM 为因变量，EM 用线性概率模型便于解释方差）
```
y_{q c s r} = μ + β·X_c                      # 条件的固定效应：温度、缓存、精度及其交互
            + u_q                             # 题目随机截距        ~ N(0, σ²_q)
            + v_{q c}                         # 题目 × 条件交互      ~ N(0, σ²_qc)
            + w_{q c s}                       # 种子（嵌套于 q×c）   ~ N(0, σ²_s)
            + ε_{q c s r}                     # 同种子重复残差       ~ N(0, σ²_r)   ← 服务栈非确定性
```
- 方差成分解读：σ²_q = 题目难度差异；σ²_qc = 条件对不同题目影响不同；σ²_s = 采样随机性；σ²_r = 服务栈数值非确定性。
- 关心的对比：各成分占总方差的比例（类似 ICC），以及 σ²_s、σ²_r 是否随缓存、精度变化。为此可让 σ²_s、σ²_r 按条件分组估计（异方差模型），或按条件分别拟合后比较。
- 敏感性分析：EM 用广义线性混合模型（logit 链接）在潜变量尺度上重算；结论若与线性概率模型方向一致，报告主模型即可。
- 软件：R `lme4` / `glmmTMB`；分析脚本放 `analysis/`，由 `make figures` 调用。

### 4.2 行为层面
- 不同动作序列数、首次分歧步：按条件做描述统计 + 置换检验（不强行套混合模型）。
- 与 2602.11619 对照：报告"每题 10 次运行的不同动作序列数"。

## 5. 需要多少（Q2：概化理论 + 功效分析）
用 4.1 估出的方差成分做概化理论（generalizability theory）的 D-study：

- **单个系统的评测均值**，n_q 道题、每题 n_r 次重复：
  `Var(均值) ≈ σ²_q / n_q + (σ²_s + σ²_r) / (n_q · n_r)`
- **两个系统（条件）比较**，同一组题：题目主效应相减抵消，误差来自交互和运行噪声：
  `Var(差值) ≈ 2 · [ σ²_qc / n_q + (σ²_s + σ²_r) / (n_q · n_r) ]`
- 由此给出：
  1. 目标标准误（如 ±1 个百分点）下 n_q 与 n_r 的权衡曲线（等高线图）；
  2. 检测给定差值 Δ（如 2 个百分点）、功效 0.8 时所需的 (n_q, n_r) 组合；
  3. 固定预算 B = n_q · n_r 下的最优分配（对应 Low 组"近最优区域"的思路）。
- 用模拟（从拟合的方差成分抽样）验证解析公式，特别是 EM 为 0/1 时近似是否成立。
- 产出：一个可运行的"实验设计计算器"（输入方差成分和目标，输出 n_q、n_r），即 CLAUDE.md 里的研究产出 2。

## 6. 多重比较与报告
- 条件对比用 Holm 校正；方差成分报告点估计 + 95% CI。
  - 2026-10-03 修订：CI 改用**按题目重抽样的 bootstrap**（cluster bootstrap），而不是参数 bootstrap。理由：EM 是 0/1 变量，大量题目全对或全错，参数 bootstrap 依赖的正态随机效应假设不成立；按题目重抽样保留了题内的种子/重复结构，不依赖分布假设。
  - 比较两个条件的 D-study 改为按具体对比估计交互方差（analysis/04_dstudy_pairs.R），见 E01_design.md。
  - 2026-10-03 晚修订（依据独立的静态代码审查）：第 5 节的公式把每题 n_r 次运行当作独立采样，但实际设计是"S 个种子 × R 次同种子重复"，且比较两个条件时用的是同一组种子。现改为按"题目 → 种子 → 同种子重复"分解**配对差值**的方差（矩估计），外推时 n_r 定义为"每题、每个条件 n_r 次独立运行（每次新种子、不做同种子重复）"。同时报告两种外推：**种子配对**（两个条件用同一组种子，同种子的结果相关、差值方差更小）与**种子独立**（例如比较两个不同模型，种子不再关联）。功效改为完整的双侧公式 Φ(Δ/SE−z)+Φ(−Δ/SE−z)。单个系统的标准误（02）只保留"n_r 次独立运行"的解释，比较部分移到 04。
- 借鉴 2610.00447：报告分数时附"配置卡"（模型、精度、服务栈、缓存、采样参数、种子方案），并区分"描述性的排名变化"和"同时推断后仍显著的变化"。
- 零方差格子（如 T=0 + 关缓存）如实报告为 0，并给出上界（如 0/N 的 95% 上界 ≈ 3/N）。

## 7. E00 预实验在这个方案里的角色
- 只做描述 + 粗估方差成分量级，**不做假设检验**；用于决定正式实验的 n_q、n_r 和是否启用同种子重复。
- 建议的 E00 调整（待确认，已根据彩排 E00R 更新）：`n_questions: 30–50, n_repeats: 10, replicates_per_seed: 2`（5 种子 × 2 次）。彩排显示方差集中在少数题目上，增加题数比增加重复次数更有用；同种子重复用来分离服务栈非确定性。

## 8. 已确认的决定（2026-10-03，见 docs/decisions.md）
1. 主结局 EM，F1 为次结局。
2. 主模型为线性混合模型（EM 作 0/1 线性概率），logit GLMM 作敏感性分析。
3. E00 起启用同种子重复（replicates_per_seed: 2）。
4. 分析软件 R（lme4 / glmmTMB）。
5. "可靠"的主定义：同一组题上两个条件相差 3 个百分点时功效 0.8（α=0.05）；另报告标准误曲线和排序翻转概率。
6. 采样参数：正式实验以 Qwen3 官方非思考推荐为主；E01 起加入 top_p=1、不设 top_k 的对照。
