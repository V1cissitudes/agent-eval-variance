### H1：同种子重复的一致性（预登记）
| 实验臂 | 缓存关 | 缓存开 |
|---|---|---|
| greedy | 0/300（上界 1.2%） | 25/300 = 8.3% [5.5, 12.1] |
| qwen | 0/900（上界 0.41%） | 38/900 = 4.2% [3.0, 5.8] |
| topp1 | 0/900（上界 0.41%） | 51/900 = 5.7% [4.3, 7.4] |

**H1 成立**：关缓存时三个臂共 2,100 组同种子重复全部完全一致；开缓存时不一致率显著大于 0。

### 探索性发现（未预登记）：缓存分歧集中在"第一次计算 vs 复用缓存"
开缓存时，每道题在一个臂里的第一对重复（种子 0：第一次运行时缓存未命中，第二次命中）不一致率远高于之后的重复：

| | 第一对 | 之后各对 |
|---|---|---|
| E00，T=0 | 3/40 = 7.5% | 0/160 |
| E01a greedy（T=0） | 25/300 = 8.3% | — |
| E01a qwen（T=0.7） | 26/300 = 8.7% | 12/600 = 2.0% |
| E01a topp1（T=0.7） | 31/300 = 10.3% | 20/600 = 3.3% |

解读：差异来自"完整计算"和"复用 KV 缓存"两条计算路径的数值差别（与 2609.04748 的机制一致）。缓存热起来之后，贪心下的重复运行又完全一致。**方法含义**：开缓存时只看"重复运行结果一致"会低估真实的不确定性；评测结果还会依赖运行顺序和缓存冷热。这也解释了 E00（每题 5 对，只有第一对受影响）与 E01a 表面比例的差异。

### 准确率（线性混合模型）
各臂准确率 50.2–51.3%；臂和缓存的效应都在 1.4 个百分点以内（SE 1.1–1.6），无显著差异。logit GLMM 受准分离影响（大量题目全对或全错），系数没有意义，只作为"无法估计"记录。

### D-study（按具体对比；检测 3 个百分点，双侧 α=0.05）
2026-10-03 晚按修订方法重算（配对差值的"题目 → 种子 → 同种子重复"分解；n_r = 每题每条件的独立运行数）。两种外推：**种子独立**（两个条件的种子互不相关，例如比较两个不同模型）和**种子配对**（两个条件用同一组种子）。

| 对比（同一组题） | 种子独立：100×1 / 300×1 / 300×3 / 300×5 | 种子配对：100×1 / 300×1 / 300×3 |
|---|---|---|
| qwen：缓存关 vs 开 | 0.25 / 0.61 / 0.96 / 1.00 | 0.54 / 0.95 / 1.00 |
| topp1：缓存关 vs 开 | 0.19 / 0.45 / 0.89 / 0.98 | 0.40 / 0.84 / 1.00 |
| qwen vs topp1（缓存关） | 0.21 / 0.52 / 0.92 / 0.99 | 0.40 / 0.84 / 1.00 |
| qwen vs topp1（缓存开） | 0.21 / 0.51 / 0.92 / 0.99 | 0.36 / 0.79 / 1.00 |
| greedy：缓存关 vs 开 | 0.39 / 0.83 / 0.90 / 0.91 | 同左（温度 0 没有采样） |

- **排序翻转概率**（真实差 3 个百分点，温度 0.7）：种子独立时，100 题 × 1 次为 **10–14%**，300 题 × 1 次为 1.3–3.3%；种子配对时，100 题 × 1 次降到 2–6%。
- **方法含义**：比较两个条件时固定使用同一组种子（公共随机数），能明显提高功效。
- 题目 × 条件交互方差很小（≤ 0.0023），这些对比的条件都很相似；比较差别更大的系统时交互方差会更大，需要更多题目。贪心解码下缓存开关的差异来自第一次计算的翻转，重复的作用有限。
- 修订前的版本把 6 次嵌套运行当作独立样本，高估了重复次数的作用；表中数字已全部替换。

## 结论
1. **关缓存时，这个服务栈上的重复运行完全可复现**（2,100 组同种子重复全部一致），所以"重复运行方差"可以干净地分解为题目和种子两部分。
2. **前缀缓存带来 2–3% 的服务栈方差**，而且主要来自每道题第一次计算与复用缓存之间的差别；开缓存时重复运行"看起来一致"会低估不确定性。
3. **采样方案改变方差但不改变准确率**：不截断的采样（top_p=1）让种子方差占比从约 9% 升到约 16%。
4. **方差的 84–100% 来自题目之间**。温度 0.7、种子独立时，300 题 × 3 次功效约 0.9–0.96；每题只跑一次、100 题时，有 10–14% 的概率把真实差 3 个百分点的两个条件排反。比较时固定使用同一组种子，可以把这个概率降到 2–6%。
