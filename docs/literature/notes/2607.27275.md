# 2607.27275 Flat Score, Amplified Failures: How the Error Budget Masks Damage in Quantized LLM Agents

- arXiv 2026-07-29 ｜ https://arxiv.org/abs/2607.27275
- 阅读：2026-10-03，基于 arXiv HTML 全文的要点提取（数字为原文引用）。

## 设置
- 模型：Gemma-4（31B dense、26B-A4B MoE）、Qwen-3.6（27B dense、35B-A3B MoE），另有 Qwen-3.5 27B、9B。
- 精度：BF16（参照）、FP8 仅权重、INT4 仅权重（AWQ；Gemma 用 g=32，Qwen 用零点 AWQ、g=128）。
- 服务：vLLM，A100，KV cache 16 位；FP8 在 A100 上用 Marlin（W8A16）内核，因为 A100 没有原生 FP8。
- 任务：τ²-bench 零售、电信各 114 个任务；num_trials=4（每格 456 次模拟）；agent 贪心解码，用户模拟器温度 0.7。

## 主要发现
- **最终分数基本持平**：最大配对下降 2.0 分；多重比较校正后没有显著的分数变化。
- **过程损伤被放大**：例如 Gemma-4 dense 电信域，工具名幻觉率 19.5% → 38.3%。
- 原因是"错误预算"：环境允许若干次失败的工具调用，把损伤吸收掉；把预算从 K=10 收紧到 K=2，差距从 1.3 分扩大到 16.7 分。
- 统计：按任务聚类的 bootstrap（5000 次）；等价检验 TOST，界限 ±7.5 分。
- 运行间噪声只用一次重复粗估：均值变化约 1.5 分。

## 局限
- 一个基准、两个领域、仅权重量化、A100 + 16 位 KV；"倾向性"结论只有两个模型族支持。
- **没有系统测量重复运行方差**（只有单次重复的粗估），这正是我们的切入点。

## 对本项目的意义
1. **精度阶梯参考**：Qwen 系列的 INT4 用零点 AWQ（g=128）、FP8 仅权重；我们在 RTX 5070（Blackwell）上有原生 FP8，内核路径会不同，报告时要写明。
2. **H4 应加等价检验**：只说"不显著"不能证明"没变化"。建议在 E01b 的 H4 中加入 TOST（界限可用我们的 3 个百分点，与"可靠"的定义一致）——需在 E01b 运行前确认。
3. **过程指标**：除 EM 外，记录格式错误、搜索次数、首次分歧步等过程层面的指标；我们的轨迹已全部记录，可以直接检验"分数持平、过程受损"在我们的设置下是否成立。
4. 他们 1.5 分的噪声底只是单次重复的粗估；我们的 E00/E01 能给出这一量的严格估计和置信区间，可以直接作为对比引用。
