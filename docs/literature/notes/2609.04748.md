# 2609.04748 Same Request, Different Answer: Quantization Amplifies Cache-Induced Divergence in LLM Serving

- arXiv 2026-09-04 ｜ https://arxiv.org/abs/2609.04748
- 阅读：2026-10-03，基于 arXiv HTML 全文的要点提取（数字为原文引用）；细节以原文为准。

## 设置
- 模型：Qwen2.5-7B、Qwen2.5-14B、Llama-3.1-8B；精度 F16、Q8_0、Q4_K_M、Q3_K_M。
- 服务栈：llama.cpp（b10434）与 vLLM 0.11.0；RTX 4090；**batch size 1（串行）**。
- **只用贪心解码**：temperature 0，固定种子 42。
- 任务：BFCL 多轮（每配置 80 个 episode，每个约 10 次请求）；另有 GSM8K。
- 分歧定义：token id 层面任何差异即算分歧。

## 主要结果
- **关缓存：800 个 episode 中 0 个分歧**（单配置上界 4.6%，合并上界 0.5%）→ 位级可复现。
- 开缓存（同臂重复）：Qwen2.5-7B F16 20.0% [12.7–30.0]，Q8_0 55.0%，Q4_K_M 77.5%，Q3_K_M 67.5%；趋势检验 z=5.68, p=1.3×10⁻⁸。
- 开缓存 vs 关缓存（跨臂）：F16 36.2%，Q4_K_M 75.0%。
- llama.cpp 关闭主机内存 prompt cache 层：分歧从 38.8% 降到 1.2%（一个开关）。
- 正确率层面：1300 题中 20 次翻转（13 次偏向缓存、7 次偏向重算），McNemar p=0.26 → 方向无偏，净准确率不变。
- 分歧集中在 episode 前段（置换检验 p=0.0002）。

## 机制
- 复用 KV 改变浮点累加顺序，浮点加法不满足结合律 → 数值微小差异。
- 量化压缩了候选 token 之间的 logit 差距 → 更小的扰动就能改变 argmax。（相关：2608.06564 发现量化把决策 margin 线性压缩 m' ≈ c·m + b，c<1。）

## 局限
- 7–14B、单张消费级 GPU、英文、BFCL+GSM8K；agent 任务成功率接近地板（1.2–18.8%）。
- **没有温度采样**；没有多租户/批处理>1 的条件。

## 对本项目的意义（重要）
1. **零方差风险被证实**：vLLM + 贪心 + batch 1 + 关缓存 → 重复运行位级相同。E00 的 T=0 / cache-off 格子预期方差为 0——这本身是需要验证并报告的结果，不是失败。
2. **温度 > 0 是他们没做的**：采样下，"种子带来的方差"和"服务栈数值非确定性"会叠加。要把两者分开，设计上需要**同一种子的重复**（同种子重复之间的差异 = 服务栈非确定性；不同种子之间 = 采样方差）。见 docs/experiments/analysis_plan.md。
3. 我们的 runner 是串行的（等价于 batch 1），和他们的条件一致，结果可比。
4. 精度 × 缓存交互是他们的核心发现；我们的精度阶梯实验应以此为直接对照，并在采样条件下检验交互是否依然存在。
