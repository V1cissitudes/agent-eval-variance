# 2610.00447 Frozen Scenes, Shifting Winners: Configuration Fragility in Text-to-3D Evaluation

- 作者：Anson Y. Lam, Shuqing Li, Michael R. Lyu（CUHK）｜ arXiv 2026-09-30 ｜ https://arxiv.org/abs/2610.00447
- 来源：2026-10-03 检索发现；同日基于 arXiv HTML 全文补读方法细节（数字为原文引用）。

## 设置
- 冻结 300 个场景（50 个 prompt × 6 个生成器），19 个对齐评测器 + 1 个感知质量对照（CLIP-IQA）。
- 8 个因素**逐个独立扫描（OFAT）**：分辨率 9 档、焦距 7、光照 8、背景 10、俯仰 7、偏航 8、caption 模板 337 条语法路径、改写 8–11 条；共享协议 387 个（基线 + 386 个水平）。

## 方法
- **描述性的方差比**，不是随机效应模型：ρ(f) = E_s[Var_ℓ σ_{s,ℓ}] / Var_m(E_p σ_{m,p,c0})，即"场景内跨配置的方差"除以"默认配置下生成器均值之间的方差"。另用归一化极差衡量离散度。
- 区间：按 prompt 块重抽样（B=2000），生成器、评测器和配置在每个 prompt 内保持对齐。
- 同时推断：对 J=110,295 个配对对比，用 bootstrap 最大标准化偏差构造近似同时置信带（q0.95=4.397）；作者说明这是探索性覆盖，不是有限样本的族错误率保证。
- 报告建议：(生成器, 分数, 配置卡 ID)，配置卡 ID 是带版本的哈希，包含渲染协议、caption 协议、视角策略、评测器身份、不确定性规则。

## 结果
- 17/19 个评测器的峰值 ρ > 1，其中 11/19 的 bootstrap 下界 > 1；18/19 中 caption 模板的影响大于任何渲染因素。
- 18/19 在某些配置下会换点估计冠军，但同时推断后 0/19 存在反向的比较；排名比分数稳定（Kendall's W 中位数最小值 0.80）。

## 局限（作者自述）
- OFAT 设计，**不估计因素间交互**；只覆盖这 6 个生成器和 50 个 prompt；没有人工验证；约一半改写未通过语义保持审查。

## 对本项目的意义
1. **方法对照**：他们是 OFAT + 描述性方差比；我们是析因设计 + 混合效应模型，能估计交互（缓存 × 精度、温度 × 缓存），这是明确的方法优势，写论文时可以直接对比。
2. **借鉴**：①按题目整块重抽样的 bootstrap（我们已采用）；②大量对比时的同时推断（我们比较的条件对较少，Holm 足够，但 E01b 精度阶梯对比变多后可考虑 bootstrap 最大 t）；③**配置卡**：我们的轨迹已记录条件和 git commit，可再加一个配置哈希，作为报告时的"run card ID"。
3. 他们的"换冠军但不显著"区分（描述性 vs 同时推断后仍成立），对应我们 D-study 里的排序翻转概率，写结果时应同样区分。
