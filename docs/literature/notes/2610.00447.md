# 2610.00447 Frozen Scenes, Shifting Winners: Configuration Fragility in Text-to-3D Evaluation

- 作者：Anson Y. Lam, Shuqing Li, Michael R. Lyu（CUHK）｜ arXiv 2026-09-30 ｜ https://arxiv.org/abs/2610.00447
- 来源：2026-10-03 检索发现；以下仅基于摘要，**全文待精读**。

## 摘要要点
- 生成结果固定（300 个场景、6 个生成器），只改评测协议的 8 个因素（渲染相机、caption 措辞等），对 19 个对齐评测器做审计。
- 17/19 个评测器的"峰值配置方差"超过"生成器之间的方差"；18/19 在某些配置下会换点估计冠军。
- 排名比分数稳定；在对全部搜索做同时推断后，没有一个排名反转是显著的 → 观察到的换冠军是描述性的，不是确认的优劣变化。
- 建议：报告 (生成器, 分数, 配置卡 ID)，并做"选择感知"（selection-aware）的不确定性分析。

## 和本项目的关系
- **同一个问题，不同对象**：他们把"评测配置"当作测量协议的一部分做方差分解；我们把推理服务配置、权重精度、采样设置、种子当作 LLM agent 评测的测量协议。
- 可借鉴：①"配置方差 vs 被比较对象之间方差"的比较框架，正好对应我们"服务配置方差 vs 模型/题目方差"；②同时推断（simultaneous inference）防止在大量配置里挑出假阳性的排名反转；③报告时附配置 ID。
- 区别：他们的生成结果是冻结的、评测是确定性渲染；我们的 agent 输出本身是随机的（多步、工具调用），重复运行方差是核心对象。
- 精读时关注：方差分解的具体模型（是否混合效应）、prompt-bootstrap 下界的做法、多重比较校正方式。
